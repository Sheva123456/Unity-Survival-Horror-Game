**Game Description**

This project is a survival horror game in which the player must find a way out of a haunted house. An enemy patrols the house and will chase and damage the player if they enter its detection range. The player must search for clues, avoid the enemy, and solve the puzzle through trial and error. The game is intentionally designed so that players are unlikely to solve the puzzle on their first attempt. They are expected to fail and die multiple times, using the knowledge gained from each attempt to eventually discover the correct solution and escape.

**How to Run**

*Prerequisites*

Before running the project, make sure you have installed:

- Unity Hub

- Unity Editor 6000.4.8f1

*Installation*

1. Clone or download this repository.

2. Open Unity Hub.

3. Click Add and select the downloaded project folder.

4. Open the project using Unity Editor 6000.4.8f1.

5. Wait for Unity to finish importing all project assets.

*Running the Game*

1. In the Unity Editor, navigate to the Assets/Scenes folder.

2. Open the main game scene.

3. Click the Play button at the top of the Unity Editor to start the game.
